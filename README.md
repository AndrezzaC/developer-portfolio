# Developer Portfolio

Meu portfólio como desenvolvedora, criado para reunir meus principais projetos e apresentar minha evolução na área de desenvolvimento backend.

## Tecnologias

- HTML5
- CSS3
- JavaScript (em desenvolvimento)
- Font Awesome

## Funcionalidades

- Navegação por menu
- Layout moderno com Glassmorphism
- Seção Sobre
- Tecnologias
- Projetos
- Contato
- Links para GitHub, LinkedIn e e-mail

## Projetos apresentados

- Sistema de Compras
- Sistema de Tarefas
- Sistema de Veículos
- VetCare API

## Objetivo

Este projeto foi desenvolvido para praticar HTML, CSS e JavaScript, reunindo meus principais projetos em um portfólio profissional. Ele continuará sendo atualizado conforme minha evolução como desenvolvedora.
