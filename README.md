# Developer Portfolio

Meu portfólio como desenvolvedora, criado para reunir meus principais projetos e apresentar minha evolução na área de desenvolvimento backend.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (em desenvolvimento)
- Font Awesome

## Funcionalidades

- Navegação por menu
- Layout moderno com Glassmorphism
- Seção Sobre
- Tecnologias
- Projetos
- Contato
- Links para GitHub, LinkedIn e e-mail

## Projetos apresentados

- Sistema de Compras
- Sistema de Tarefas
- Sistema de Veículos
- VetCare API

## Objetivo

Este projeto foi desenvolvido para praticar HTML e CSS e servir como meu portfólio profissional. A próxima etapa será adicionar interatividade utilizando JavaScript.
